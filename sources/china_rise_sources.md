# Sources & Fact Sheet — "The Rise of China as a Superpower"

Research file for the episode. Every claim used in narration should trace back to a row here.

**Status key**

| Tag | Meaning |
|---|---|
| ✅ VERIFIED | Well-documented in primary or authoritative sources (World Bank, IMF, UN, official records, standard academic histories). Safe to state as fact. |
| ⚠️ RANGE / CONTESTED | The event is real but figures or interpretation vary. Narrate with a range or with attribution ("historians estimate…"). |
| ❌ APOCRYPHAL | Popular but unverified or misattributed. **Do not** present as fact. If used, frame it as legend ("a quote often attributed to…"). |

**Narration rule for GDP comparisons:** always say *which* measure. "Largest economy by purchasing power (PPP)" is true; "largest economy" in nominal dollars is **not** (as of 2024–2025 data, the US is larger).

## 4. Balance & Accuracy Checklist

The channel's credibility depends on telling the full story. The script must:

- [ ] Acknowledge the human cost of the Mao era (Great Leap famine, Cultural Revolution) using ranges.
- [ ] Mention 1989 factually.
- [ ] Separate nominal GDP from PPP GDP.
- [ ] Note that "eradicating absolute poverty" (2021) uses China's national line, which differs from World Bank lines.
- [ ] Include present-day headwinds: aging/shrinking population, property and local-government debt, youth unemployment, US–China tech and trade tensions.
- [ ] Avoid stating a "superpower" verdict as fact — present the debate.
- [ ] Re-check every 🔄 figure before upload.
