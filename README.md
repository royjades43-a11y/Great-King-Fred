# Great-King-Fred: Engineering Failure Studio

A team of Claude Code assistants that make ~10 minute documentaries about engineering failures. You type a topic, record the narration, and get a finished 1080p video with real footage, evidence-board graphics and word-by-word captions.

## You need
- A Claude plan with Claude Code, used in the **Code** tab of the Claude desktop app (not normal chat)
- An ElevenLabs account for the narrator voice

## Use it
1. Open this folder in the Code tab and type **follow SETUP.md**. Claude installs everything it needs, once.
2. Type **make a documentary about the Hyatt Regency walkway collapse** (or any topic). Claude reads the official investigation report, plans the episode, downloads free-to-use footage with credits, writes and fact-checks the script, and gives you the voiceover text.
3. Paste the text into ElevenLabs, choose a calm documentary voice, and download the MP3.
4. Drag the MP3 into the chat and type **make the video**. Claude times every word, cuts the footage to it, checks the frames, renders 1080p, and writes your YouTube description with chapters and credits.
5. Watch the whole thing before you upload. Ask for any change in plain English.

See `CLAUDE.md` for how the team is organised, and `.claude/agents/` for each assistant.
